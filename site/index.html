        Choose a Word file (.docx), a PDF, or a photo (JPEG, PNG, or HEIC). The file stays in this browser. This clears author names, the last-modified-by name, and personal document properties when they are present. Tracked deleted text stays in the document.             Hidden content check
            
      
            Choose a PDF, a Word file (.docx), or an Excel file (.xlsx). This looks for text under dark boxes in a PDF, white or hidden text in Word and PDF, and hidden sheets, rows, or columns in Excel. It only reports. It can miss things, and it does not change the file. The file stays in this browser. You must review before you rely on it.

                Scanned pages are not read on this page. OCR stays off unless you open a separate page and choose the download. That download is the engine and English data from this site only. The airplane-mode self-test covers this page, not those extra files. Optional OCR.
                
    
                

    
                
      
                Airplane-mode self-test
                
      
                One click scrubs and restores sample text in this tab, then counts requests with PerformanceObserver and resource timing during that run. File tools are loaded with the page, and those earlier requests are not part of the count. This page is built with connect-src 'none', so the browser blocks connections from the page. The count does not detect airplane mode, and it does not cover extensions, other apps, or the rest of the device.
